# NOVA Studio

Proyecto final del Módulo I de HTML y CSS.

## Idea de negocio

NOVA Studio es una propuesta de centro de bienestar y estética que ofrece servicios de cuidado facial, corporal y relajación.

## Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media queries para diseño responsive

## Secciones

- Barra de navegación
- Hero principal
- Nosotros
- Servicios
- Beneficios
- Contacto
- Footer
